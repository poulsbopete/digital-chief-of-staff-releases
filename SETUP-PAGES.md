# Enable GitHub Pages (one time)

After the first push to `main`, the **Deploy GitHub Pages** workflow publishes `docs/` to the `gh-pages` branch.

1. Open **Settings → Pages**
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `gh-pages` / `/ (root)`
4. Save

Site URL: **https://poulsbopete.github.io/digital-chief-of-staff-releases/**

If the workflow has not run yet, wait for the green check on the Actions tab, then configure Pages.
